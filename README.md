# Internconnect

A rule-based web application designed to recommend internship opportunities based on user qualifications, skills, and background.

## 🚀 Live Demo
[View Live Application](https://internconnect-dc8i.onrender.com)

## 🛠️ Tech Stack
* **Backend:** Java, Spring Boot, Spring Data JPA
* **Frontend:** Thymeleaf, HTML5, CSS3, JavaScript
* **Database:** H2 In-Memory Database / MySQL
* **Deployment:** Render

## 📌 Key Features
* User registration and authentication
* Smart internship recommendation engine
* Interactive user dashboard
